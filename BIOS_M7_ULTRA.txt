💡 Notes d'expert pour cette page :
Setup Prompt Timeout : Passer de 2 à 5 secondes est une petite astuce de confort. Comme tu utilises un clavier sans fil (Logitech K360), cela laisse le temps au dongle de s'initialiser pour que tu puisses réagir si tu dois retourner dans le BIOS.
Boot Option #1 : C'est parfait. Tant qu'une clé USB bootable est branchée, le GMKtec démarrera dessus. Une fois l'installation terminée et la clé retirée, il passera automatiquement à l'option #2 (ton SSD).
Windows Boot Manager : Ne t'inquiète pas de ce nom, ton installation Debian va écraser cette entrée proprement.

Petit conseil pour ton 04-network.sh :
Puisque tu vas avoir deux fichiers de configuration réseau, quand ton script de réseau s'exécutera, il modifiera probablement /etc/network/interfaces pour ajouter tes bridges (br-ext, ovs-lab).
Pour éviter que ton Wi-Fi ne tombe à ce moment-là, ne fais pas systemctl restart networking. Utilise plutôt des commandes ciblées pour monter tes nouveaux bridges :
bash
ifup br-ext
ifup ovs-lab
